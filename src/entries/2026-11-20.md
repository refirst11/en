---
title: The Wheel I Built Twice
date: '2026-11/20'
---

I built TypedCSS because it was easy.

Plumeria already had the compiler, the bundler plugins, the ESLint rules and the type definitions. Putting a StyleX-shaped API on top of them was technically simple, and the work was fun. Nine packages went to npm under `@typedcss`, with a domain to match.

It was a reinvention of StyleX. I knew that going in, and I told myself the difference would show up once it existed.

It did not.

## Looking for the Difference

When I sat down to write why someone should pick TypedCSS, every reason I wrote was also a reason to pick StyleX. Atomic CSS, compiled at build time, typed style objects, last style wins. All true, and all things StyleX already does, with Meta behind it.

Justifying TypedCSS turned out to be the same exercise as justifying StyleX. And StyleX does not need me to justify it.

Plumeria is different. It makes choices StyleX does not make, and I can defend each of them. TypedCSS made no choice of its own. It was a second door into the same room.

Worse, it worked against Plumeria. If I was willing to ship a StyleX clone myself, what was left of the case that Plumeria needed to exist? Every week TypedCSS stayed up, that case got weaker.

## Letting It Go

So I wound it down:

- Every `@typedcss` package on npm is deprecated and points to Plumeria.
- typedcss.dev redirects to plumeria.dev.

The whole experiment cost me one thing: the domain fee.

The one part worth keeping was not the API. It was the CSS type definitions underneath, which every project like this has to maintain by hand. They now live on their own as [cssdefs](https://www.npmjs.com/package/cssdefs), regenerated every week from MDN and webref, and Plumeria is its first user.

## What I Am Writing Down

Being easy to build is not a reason to build something. Before the next one, I want to be able to finish one sentence first: what does this do that nothing else does?

If I cannot finish it, the answer is to contribute to what already exists, or to build the smaller piece that is missing.
